# 2026-11-02

## 关于页改为「版本 / 更新内容」选项卡

- **现象**：「我的」底部「关于」卡片里版本信息和 CHANGELOG 更新说明全挤在一起，一大段纯文本，老人和家人都看不清改了什么。
- **改动**：卡片改为「版本 / 更新内容」两个选项卡（复用 `.segmented`）。
  - 「版本」：应用名、版本号、Commit、提交时间、发布构建时间。
  - 「更新」：`parseReleaseNotes()` 把 CHANGELOG 片段解析为 h2/h3/p/li，`renderNoteInline()` 支持 `**加粗**` 与 `` `等宽` ``，CSS 新增 `.about-notes` 及 note-* 样式。
- **为什么**：提升可读性，家人看更新内容时能快速找到重点。
- **实现要点**：不改 buildInfo 生成逻辑，仅在 UI 层解析 markdown 片段；选项卡状态 `aboutTab` 放 App 组件内，切换时保留滚动位置。

## 验证

- `npm run lint` / `npm run build` 通过。
- Playwright 本机模式（临时禁用云端）截图验证：选项卡切换正常，「版本」显示 Commit/时间，「更新内容」显示结构化列表（标题、加粗、列表点）。验完已还原 `supabase.ts`。
