# 2026-11-13

## 关于页新增常驻「下载 APK」按钮

### 改了什么

- 「我的 → 关于」版本卡片里新增一个常驻的大按钮「下载 APK（安卓安装包）」，排在「检查更新」上方，点击直接下载最新 APK。不再只有“发现新版本”时才出现下载链接。
- `src/lib/update.ts` 新增 `LATEST_APK_URL`（`https://github.com/cainaxin/baby-food-tracking/releases/latest/download/baby-food-tracker-latest.apk`）与 `RELEASES_PAGE_URL` 常量，按钮固定指向 latest 别名资产，永远解析到最新版。
- `scripts/release.mjs` 发版时在版本号 APK 之外额外上传一份 `baby-food-tracker-latest.apk`（复用同一字节），保证固定链接始终可用；清理旧资产时一并删除。

### 为什么

- 之前 APK 下载链接只在「检查更新」发现新版时才出现，家人第一次安装 APK 仍然要去 GitHub 找，不友好。
- 网页常驻下载入口后，安卓手机浏览器打开网页 → 我的 → 关于 → 一键下载安装，链路闭环。
- 用 `releases/latest/download/<name>` 固定地址 + latest 别名资产，避免按钮链接写死某个版本号后很快失效。

### 验证

- `npm run build`、`npm run lint` 通过。
- 待发版 v0.9.2 后验证：手机浏览器下载按钮可用；路由器自动更新（release published 触发 deploy.yml）；应用内「检查更新」识别 0.9.2。
