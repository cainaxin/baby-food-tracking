# 2026-11-23

## 每日小结：显示生成日期时间 + 非当天自动清空（v0.9.4）

### 改了什么

- **`src/lib/backend.ts`**：`getDailySummary` 额外返回 `createdAt`（数据库 `created_at` 字段 / 本地缓存的 `createdAt`）；本地缓存格式从纯字符串改为 `{ text, createdAt }` 对象，兼容旧格式。
- **`src/lib/summary.ts`**：`DailySummary` 类型加 `createdAt` 字段；所有返回路径都带生成时间。
- **`src/App.tsx`**：`DailySummaryCard` 展示「生成于 YYYY-MM-DD HH:mm」；加载缓存时如果发现小结的生成日期不是今天（仅当天视图生效），自动清空；修了清空后「生成小结」按钮不响应的 bug。

### 为什么

- 之前显示的生成时间是打开页面的 `formatTime(new Date())`，不管小结实际是啥时候生成的，老人容易误以为是最新分析。
- 隔天打开还显示昨天生成的小结，数据过时，应该清空重来。

### 验证

- `npm run build`、`npm run lint` 通过。
