# 2026-11-04

## 外出按时长统计（历史 / 每日统计）

- **现象**：历史页与每日统计里「外出」只显示次数，看不出在外面待了多久。
- **改动**：
  - `time.ts`：抽出通用 `spanMinutesOnDay()`，睡眠/外出共用跨日拆分；新增 `outingMinutesOnDay()`。
  - `dayStats()` 增加 `outingMin`（按日重叠拆分求和）。
  - 每日统计「外出」卡片：主值改为当日外出总时长，副行显示「共 N 次」。
  - 变化曲线新增「外出」维度（分钟），与睡眠一样用 `formatMinutes` 展示。
  - 时间线明细：外出记录显示 `几点到几点 · 时长`，未结束的显示「从 xx 起 · 已外出多久」。
- **为什么**：家人更关心「今天在外面待了多久」，尤其推车散步、遛弯这类记录。
- **实现要点**：跨天外出按重叠区间拆到各日，和睡眠同一套规则；未填结束时间算到当前时刻，单次上限 18 小时防忘填虚高。
