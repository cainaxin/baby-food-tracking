# 2026-11-04 · v0.4.1 每日小结体验优化

**标签**：`ui` `summary` `ai` `cache`

## 需求

1. 首页每日小结排版不好看 → 优化
2. 生成后全家共享，不重复生成（省 API 费用）
3. 历史日期也能生成小结

## 改动

- **排版**：`DailySummaryCard` 重写——分段展示、列表项圆点、「已生成」徽章、按钮始终可见（有缓存显示「重新生成」）。
- **缓存**：新增 `daily_summary` 表（`baby_id + day_key` 唯一），云端全家共享；本地模式用 localStorage。`fetchDailySummary` 先查缓存再调 AI。
- **历史页**：切换日期后自动加载该天小结，标题显示「X 月 X 日 · 每日小结」。

## 实现要点

- `getDailySummary` / `saveDailySummary`（backend.ts）：云端 upsert / 本地 map。
- `fetchDailySummary` 返回 `fromCache` 标志，UI 显示「全家共享，不用重复生成」。
- 切换日期/宝宝时 `useEffect` 自动加载，不需要手动点。

## Supabase

需执行 `schema.sql` 里新增的 `daily_summary` 建表 + RLS（不执行则云端缓存降级为无缓存、每次调 AI）。
