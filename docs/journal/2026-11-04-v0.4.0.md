## 外出超时提醒 + 外出不跨天（T3）

- 外出超 3 小时 / 睡觉超 12 小时未关闭 → 首页红色醒目横幅，一键去补时间。
- `outingMinutesOnDay` 改为只算开始那天，截断到当天 24:00（外出不跨天）。
- CSS 新增 `.alert-banner` 系列样式。

## 宝宝个人信息（T4）

- Baby 新增 `birthDate / gender / weightKg / heightCm`。
- BabySheet 增加生日（带月龄预览）、性别（男宝/女宝）、体重、身高字段。
- 首页宝宝卡片显示「3 个月 · 男宝 · 8.5kg · 72cm」。
- `formatMonthAge` 计算月龄（<12 月龄显示「N 个月」，否则「X 岁 Y 个月」）。
- schema.sql 补 `alter table baby add column ... gender/weight_kg/height_cm`。

## AI 每日小结（T5）

- 首页「每日小结」卡片：点「生成小结」→ DeepSeek（deepseek-chat）生成总结+建议。
- **key 安全**：走 Supabase Edge Function（`supabase/functions/daily-summary/`），key 存 `DEEPSEEK_API_KEY` 环境变量，前端代码零暴露。
- 未部署 EF 或调用失败时降级为本地统计文字（不报错，不暴露 key）。

### Supabase 部署步骤（用户需手动）

```bash
supabase functions deploy daily-summary
supabase secrets set DEEPSEEK_API_KEY=sk-xxxx  # 你的 key
```

### 安全约束

- **禁止**把 API key 写进前端代码 / VITE_ env / localStorage。
- DeepSeek key 只存 Supabase 服务端环境变量。
- Edge Function 有入参校验（prompt ≤ 4000 字符）、CORS、method 限制。
